# Reference format spec: the STORYTELLING GRAMMAR

Sources: docs/reference/ejemplo-1.MP4 (V1, "why a touchscreen feels your finger but not a pen", 91.2 s), ejemplo-2.MP4 (V2, "why Mexico throws toilet paper in the bin", 68.5 s), ejemplo-3.MP4 (V3, "how the iPhone keyboard hits keys smaller than your thumb", 88.3 s).
Method and limits as in docs/reference-style-spec.md: frames every 0.5 s plus every shot start, read in full; narration reconstructed from the burned-in subtitles (I cannot hear audio); times +-0.5 s; cited as [V1 12.0s].

Event-type legend used below: XRAY (hidden mechanism shown by cutaway/cross-section), TRANSFORM (an object changes state), MULT (copies appear: "each/all/many"), SCALE (zoom into or out of an object), CONTRAST (two actors on one stage: false belief vs truth), BEFORE/AFTER, METAPHOR (everyday scenario standing for the mechanism), NUMBER (a counter/chip carries the figure), SOURCE (a citation card), CTA (the closing ask acted out).

Tempo: a new visual event every ~5 s in V1 (18 beats / 91 s), ~3.4 s in V2 (20 beats / 68 s), ~3.7 s in V3 (24 beats / 88 s). Cuts are rare (14 / 10 / 10 shot starts); the action happens INSIDE shots through camera and object motion.

## Conversion rules: how a narration line becomes a visual event

R1. EVERY sentence gets a state change on screen. A sentence is never illustrated by a static image. In V1 there is no 3 s window without an object transform, a number change or a camera move (checked at 2 fps across 91 s); V2 and V3 are the same.
R2. THE HOOK STAGES THE FALSE BELIEF AS A CONTRAST IN THE FIRST 2-3 s: two actors on one stage, one of which fails. V1: the finger works, the pen does not [V1 0.5-6.5s]. V2: paper goes in the bin, not the bowl [V2 0.0-3.5s]. V3: a thumb larger than a key and a label saying the target is invisible [V3 0.0-3.0s].
R3. HIDDEN MECHANISM -> CUTAWAY. When the narration says "inside / under / behind / made of", dive through the surface (SCALE) into a cross-section, layer split or macro, and light the active part in the accent colour. V1 17-24 s; V2 8-13 s, 30-33 s; V3 8-13 s.
R4. "EACH / ALL / MANY" -> MULTIPLICATION. Copy the single instance until it fills the frame, and pull the camera back to show it. V1 28.5-30 s (one crossing -> hundreds, each with a number); V2 58-61 s; V3 44.5-49.5 s (mini heat-maps added per letter).
R5. EVERY NUMBER IS A SCREEN OBJECT, not only a spoken word: counters that change in place, chips with units ("4 min"), years ("2001", "2007", "2018"), arithmetic drawn as bars (10 x 44 = 440 > 320). The figure appears on the word that says it. V1 36-40 s, 75-79 s; V2 36.5-42.5 s; V3 29-35 s, 54-58 s.
R6. "BUT / EVEN IF / WHAT IF NOT" -> A COUNTER-ACTOR on the SAME stage with the same readout, so the viewer compares outcomes: pen vs finger; wool glove vs conductive thread; a raindrop vs a finger; visible keys vs touch zones [V1 4-7, 51-56, 62-65 s; V3 36-41 s].
R7. "IMAGINE..." -> A RELATABLE MICRO-SCENE with a named person and a real UI (Sofía's call, a chat to Sofía). Use it twice: set it up early with the failure, and RETURN to it later with the fixed outcome as the payoff [V1 13.5-18 s -> 57.5 s -> 66.5-68 s; V3 18.5-24 s].
R8. TIME, HISTORY, LAW OR SOURCE -> A CARD. Date chip, person photo card, book cover, patent page, corpus table, or a one-line citation under the figure (Texas Instruments; US patent number; es_50k.txt) [V1 77.5 s; V2 39.0 s; V3 58.5-63.5 s, 25.0 s].
R9. "TRY IT YOURSELF" -> A HOME EXPERIMENT shown start to end with its time chip [V2 33.5-37.5 s].
R10. THE REFRAME LINE GETS ITS OWN SINGLE-IMAGE VISUAL, not a montage: one gold thread of charge leaving the glass [V1 75-79 s]; the keyboard turning amber with the label "la diana" [V3 72-78 s]; the pipe fading to a ghost and the tile covering it [V2 54-58 s].
R11. THE CTA IS PLAYED INSIDE THE VISUAL WORLD, after the reframe: the scene becomes a phone, a finger taps Seguir, a share sheet, Enviar/"Enviado", with the share archetype in the words ("ese amigo al que nunca le funciona el móvil con las manos mojadas"; "quien defiende el bote como si fuera ley"; "ese amigo que le echa la culpa al autocorrector") [V1 81.5-87 s; V3 79-84 s; V2 61-64 s]. Then a ~4 s dimmed end card with the logo and handle.
R12. TIMING: the event starts on the keyword, +-0.3 s, and the subtitle's highlight box lands on the same word. "disuelve" -> the water plane rises [V2 32.5 s]; "conduce" -> the ions flash gold [V1 33.5 s]; "rejilla" -> the grid appears [V1 18.0 s]; "aplastan" -> neighbour zones squash [V3 35.0 s].
R13. TRANSITIONS CARRY MEANING: a blur wipe or a push-through links two ideas (macro finger -> glove scene [V1 13.0 s]; roll -> fibres [V2 29.5-30.5 s]); never a bare cut between unrelated frames.
R14. REVISIT ONE HERO RIG instead of building a new set for each fact: V1 returns to the cross-section strip about 10 times and to the glove+phone scene 5 times; each return adds one new element (a pen, ions, water, a wool loop). The rig is the visual anchor of the whole video.
R15. LABELS ARE DEMONSTRATIVE, NOT DESCRIPTIVE: 1-2 word ALL-CAPS tag with a leader line, shown only while the narrator names that thing (CRISTAL, CARGA, CRUCE, LANA; "zona de toque"). Never a sentence on screen except the subtitles.
R16. COLOUR SEMANTICS FOLLOW THE NARRATION: a part is grey until the line that activates it, then turns the accent colour (amber layer at "lo que tocas" [V3 9.5 s]; the finger glows at touch [V1 3.5 s]; wool loops stay unlit [V1 52.5 s]).

## Gap vs our current productions (record only; nothing built, no spend)
- Our v4-v6 "puntos de sutura" use ONE prop per scene with a single transformation; there is no cross-section reveal, no scale change, no multiplication, no counters or chips, no source cards, no contrast actor, no acted-out CTA, no recurring hero rig with new data per beat. Against R1-R16 the current videos satisfy R1 (v6 camera) and partly R13; every other rule is missing.
- The 91 s reference length is above our current 44 s; the beat density needed is a new event every 3.4-5 s.
- Palette conflict (references are near-black with a gold accent; ours is lavender) is flagged in the style spec for an owner decision.
