## What was verified (public web only, from this machine, 2026-10-27/28)
- YouTube: `https://www.youtube.com/@handle` returns 404 when no channel exists (negative control: a nonsense handle 404; known channels 200). "free" = 404 at check time.
- TikTok: a missing account's page carries `statusCode 10221`; an existing one carries `"uniqueId":"<handle>"` (positive and negative controls behaved). "free" = missing-account status.
- Instagram: an existing profile exposes an `og:title` with the handle; a missing profile returns a generic login page, which is indistinguishable from being blocked, so "no profile page" is PROBABLE availability only.
## What was NOT verified (outstanding, flagged)
Whether a handle can actually be registered (reserved/banned/inactive handles), other platforms, domains, trademarks in any country, search-engine collisions beyond what is stated, and how each name sounds to native speakers in every country.
A single web search found no business called "Mecanalia"; none was run for the names below.
