## 2. Lens decisions recorded

Scriptwriter led, with design and marketing consulted. There was no disagreement, and every decision rests on the readings and the calibration above (`lens-decisions.md`, 2026-11-11 "Redesign session").

1. **The `multi` supplement is rejected** on the calibration. Proofs are read under the single-object prompt only; `blind_read.py` refuses `--multi` for proofs.
2. **The prompt is recorded per reading.** The prompt kind and a hash of its text go in every reader-ledger line and every proof reading. Hashes: single `4f23b3ad4338594e`, multi `8055930bf6508141`.
3. **Proof-still conformance**, enforced in code:
   - `proof_still.py --reader` renders at `gate.STILL_POLICY` (Cycles, 540x960, 48 samples) and writes a sidecar.
   - The builder writes a conformance note with `proof_note.py --conform`.
   - `proofs.require_conforming` refuses the reading before any reader runs if the still is off-policy, off-size or has any recorded deviation. A refused reading spends nothing.
4. **One alias set per physical element per unit:**
   - `alias_sets` in `proofs.json`, linted against each proof and the script element with the same id.
   - A set holds only words the unit declared before any reading of the element. A word first seen in a failed guess never enters a set.
   - An event proof names the event, not only its carrier.
5. **Stop-loss:** at most two design rounds. A round-2 failure makes that element a boundary and returns the unit (linted).
6. **Capability boundaries** (`doctrine-topics-and-scripts.md`, "Capability boundaries"):
   - magnified tissue and cellular-scale sections
   - electric arcs and sparks as the named element, free-standing or as an accent on a carrier
   - electric current as a visible thing on its own
   - generally, an event that is a small accent on a dominant object

   Such events appear only as ungated `cues`. The electric-arc asset job is closed (status `rejected`); `arc_rig.py` is kept.
7. **Species-level declaration** of organic assets (`asset-system.md`, "Aliases of an advance job").
8. **Unit outcomes:**
   - 030 returned (boundary)
   - 029 parked
   - 022 not revived
   - 027, 026 and 028 redesigned to round 2

## 5. Deviations from the recommendation, with reasons

1. **Calibration size:** 24 readings, not about 15. These are the same whole-video packs as the 2026-11-04 calibration, for comparability, read at today's three-reader bar. Cost US$0.129, under the US$0.15 estimate.
2. **New tool `tools/calibrate_reader.py`.** The project hook blocks inline Python that spawns processes. The tool fills only a committed declaration, so it is auditable. The first launch attempt passed every pack as one argument and stopped before any reader ran: no reading taken, no cost.
3. **Conformance is enforced in code,** not only checked by the builder. B5 showed that a builder-only check lets simplified builds through.
4. **The supplement-rejected branch was taken,** so 022's N1 redesign was dropped and 028 was redesigned. This is the recommendation's own section-7 branch.
5. **028 P2 uses no `multi` pair:** the gate reads the power line, and current is a cue.
6. **028 P5 takes the raptor-asset option,** not the beat rewrite. The documented case is large birds, and a pigeon bridging two conductors would need a separate source.
7. **028 P3/P4 are rebuilt, not only re-aliased:** new asset, opaque cable. The B5 wire read as a rail.
8. **027 drops B4's taupe fallback.** The readings blame scale and count, not the grey, and the grey bands already passed (P3).
9. **026 P4 drops the alias "titanic"** (it names the carrier). This makes the proof stricter.
10. **The electric-arc job is set to `rejected`.** The library has no "closed" status.
11. **030's bank row was marked by hand.** `tools/return_topic.py` wrote the notes, INDEX, decision row and `returned.json`, but it does not mark a `standby` row. Tool gap, not fixed here.
12. **Proof-stage cost per eligible unit** (recommendation item 8) is not instrumented beyond the reader ledger. The proof unit's report must state its own session notional cost.
