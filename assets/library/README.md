# Factory asset library

Every hero object the factory has solved, one folder per object, so nothing is solved twice. Check here first: `.venv/bin/python factory/asset_library.py find <words>`.

Manual, including "How to run an asset job": `docs/current/specs/asset-system.md`. Sources: `assets/registry.yaml`.

Licence rule: CC0 preferred; Royalty-Free acceptable; CC-BY only with the attribution recorded in the asset README; anything unclear is not used.

`.blend` files and stills are local and gitignored. `asset.json`, `README.md`, `build.py` and `job/report.md` are committed.
